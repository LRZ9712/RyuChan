# 前言
这篇教程只讲证书签名不讲巨魔，如果你的机型在适合巨魔的区间，找巨魔教程看就好，签名安装不限制机型，ios全版本都可以，下边开始

# UDID
买证书之前你要获取自己设备的UDID，点击下边链接按流程操作，如果失效了，自己百度一下，这类网站很多：**ios UDID 获取**
[https://www.udids.cn/](https://www.udids.cn/)

# 证书
普遍证书都在10-20元之间，一年时间的，贵了就是被宰了，不要跟我讲售后不售后的，卖你99一本证书包售后的，够你买七八遍证书了，掉了不会自己买过吗，要他售后，至于连续掉七八次的情况我建议直接买彩票，ios证书的来源都是开发者账号花99美元申请的100个证书，99美元100本，自己算成本，来源都是一样的，没有稳不稳之差，即使运气不好掉了，就再买一本，连续掉的概率超级超级低

# 证书
![local-image:b6pffudq](/images/iosqianming/baafe0dcd6d3f5e5.png)
就这两个文件，有些商家喜欢设置密码，这个买了一定会写清楚的

# 签名软件
这个看大家喜欢。全能签，轻松签，各种签都一样的，这个就是安装软件的工具了，你装任何ipa都要经过这个软件，这边以全能签为示例

进入全能签官网：[https://sign.drnrt8.cn/sign/](https://sign.drnrt8.cn/sign/)
![local-image:a368uglo](/images/iosqianming/eae65240f179d395.png)
点我有证书，自行安装，把两个文件填进去，密码填进去，点安装,完成后会在桌面现在下载
![local-image:0aewsw1v](/images/iosqianming/8b14219a05c56b33.png)

# 配置全能签
1. 点击设置-最顶上-重新获取一遍udid
2. 导入文件-把两个证书文件导入进来

# 安装ipa
这边以香色规格为例
[https://wwbpy.lanzouq.com/inSB53rik82j](https://wwbpy.lanzouq.com/inSB53rik82j)
**密码**: 2j1a
可以装下实操下

在设置中导入文件选择要装的ipa
回到资源app页面
![local-image:fdfqmz2y](/images/iosqianming/c6395ebedb5c4586.png)
按顺序操作，签名过的包才能安装，并且只有你设备才能安装，发给别人是用不了的，到这里就安装完整了

**重点说第三个页面**
其他没什么好说的名字图标看心情改，主要是第二行 **Bundle ldentifier**
第二行，如果你要双开，比如说这是个微信的安装包ipa，你就要改第二行，在末尾加个1加个2都可以，就是不能和原来的一样，之后装第二个第三个也不能重复，要有唯一性,ok
